This policy applies to everyone using <Var name="clusterName" />, the HPC cluster of the <Var name="instituteName" /> (IGH), <Var name="hostUniversity" />.

## Rules {#rules}

- No commercial use without approval.
- Use storage reasonably: space used is monitored per user and per project. Clean up `work/` and your scratch, do not duplicate data, and remember that scratch files unused for <Var name="scratchPurgeDays" /> days are deleted (see [Storage](../hardware/storage.md)).
- Do not run intensive tasks on the login node (see [Login node etiquette](../good-conduct/login-nodes.md)).

## Violations {#violations}

- May result in account suspension.
- Report abuse to support: <Var name="supportEmail" link /> or a ticket on <Var name="supportPortal" link />.
