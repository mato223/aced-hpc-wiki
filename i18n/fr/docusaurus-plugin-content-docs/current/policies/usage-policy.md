Cette politique s'applique à toute personne utilisant <Var name="clusterName" />, le cluster HPC de l'<Var name="instituteName" /> (IGH), <Var name="hostUniversity" />.

## Règles {#rules}

- Aucune utilisation commerciale sans autorisation.
- Utilisez le stockage raisonnablement : l'espace occupé est suivi par utilisateur et par projet. Nettoyez `work/` et votre scratch, ne dupliquez pas les données, et rappelez-vous que les fichiers du scratch non utilisés depuis <Var name="scratchPurgeDays" /> jours sont supprimés (voir [Stockage](../hardware/storage.md)).
- N'exécutez pas de tâches intensives sur le nœud de connexion (voir [Bon usage du nœud de connexion](../good-conduct/login-nodes.md)).

## Infractions {#violations}

- Peuvent entraîner la suspension du compte.
- Signalez tout abus au support : <Var name="supportEmail" link /> ou par ticket sur <Var name="supportPortal" link />.
